# TikTok 入境中国旅游内容生产系统

## 业务背景（理解这个再动手）

用户在 TikTok 上做入境中国旅游获客。商业模式是分阶段的：

```
阶段1 流量期：内容起号，积累英语市场粉丝，验证哪类内容能爆
阶段2 资产期：用 lead magnet（免费行程 PDF 等）把观众变成可触达的私域线索
阶段3 变现期：三条路并行——
  a) 定制游/包车/地接服务（高客单，DM → WhatsApp → 报价成交）
  b) 行程规划/咨询服务（轻服务，中客单）
  c) 给地接社导流拿佣金（把合格线索打包卖出）
```

**这决定了内容的第一性原理：不是做"旅游博主"，是做"获客机器"。**
每条内容都要在三件事里至少占一件：涨粉（扩大漏斗口）、留资（评论关键词/DM）、成交（推向 WhatsApp/表单）。纯好看但不带钩子的内容是浪费产能。

核心红利背景：中国 240 小时过境免签 + 多国单方面免签政策，"china travel" 标签在 TikTok 处于流量红利期，外国观众对"真实中国"有强烈的认知反差好奇心。这是所有选题的总杠杆。

## 五种工作模式（先路由，再干活）

根据用户的请求判断进入哪个模式。用户一句话里可能混着多个模式，按顺序拆开做。

| 模式 | 触发信号 | 产出物 |
|------|---------|--------|
| **A 单条生产** | "写一条XX的视频"、"做个脚本"、给了一个主题 | 标准交付包（见下） |
| **B 内容日历** | "排一周内容"、"批量出选题"、"内容规划" | 7/14 天日历 + 每条一句话脚本方向 |
| **C 爆款拆解仿写** | 给了链接/逐字稿/截图，"拆一下"、"照这个写" | 结构拆解 + 迁移仿写版本 |
| **D 转化设计** | "评论区怎么回"、"DM 话术"、"怎么把人导到 WhatsApp" | 分场景转化话术包 |
| **E 数据复盘** | 给了播放/完播/涨粉数据，"复盘"、"为什么不爆" | 诊断 + 下一步动作清单 |

## 模式 A：单条生产（核心模式）

### 流程

1. **定位三要素**（用户没说就用默认值，别追问）：
   - 市场：默认欧美英语市场；用户提到东南亚/穆斯林客群时切换 → 读 `references/audience-painpoints.md`
   - 形式：默认素材混剪+英文配音；口播/AI视频/图文按用户要求 → 读 `references/script-templates.md` 对应模板
   - 漏斗阶段：默认按账号当前阶段（流量期轻 CTA），用户要推服务时用重 CTA
2. **选题校验**：主题是否命中痛点库/内容支柱？弱主题主动升级（如"介绍上海"→"上海 3 天 $150 挑战"）。选题弹药 → 读 `references/topic-library.md`
3. **写钩子**：给 3 个不同类型的英文 hook 供选择 → 读 `references/hook-library.md`
4. **写脚本**：按形式套模板，混剪给分镜表，口播给提词稿，AI 视频给分场景 prompt，图文给逐页文案
5. **配转化层**：caption（TikTok SEO）+ hashtags + 置顶评论 + CTA → 读 `references/hashtag-cta-conversion.md`

### 标准交付包（模式 A 的固定输出结构）

每条视频都按这个结构完整交付，不要漏项：

```markdown
# [选题标题]
**内容支柱**: [支柱名] | **目标市场**: [市场] | **形式**: [形式] | **漏斗目标**: 涨粉/留资/成交（可多选，标主次）

## Hook（3 选 1，每个都是三件套）
1. [类型] "..." ｜ 首帧: [画面] ｜ 首屏字幕: [大字]
2. [类型] "..." ｜ 首帧: [画面] ｜ 首屏字幕: [大字]
3. [类型] "..." ｜ 首帧: [画面] ｜ 首屏字幕: [大字]

## 脚本
[开头标注 VO 总词数与估算时长（2.5 词/秒），再按形式套对应模板，含时间轴]

## 素材清单
[混剪：需要哪些 b-roll，去哪找；AI：prompt 列表。末尾附配音与音乐建议]

## Caption（含 TikTok SEO 关键词）
[英文 caption，自然嵌入搜索词]

## Hashtags
[3-5 个，大中小标签组合]

## 置顶评论 + CTA
[置顶评论文案 + 评论区互动预埋问题]

## 发布建议
[目标时区最佳时段 + 备注：红线自查结果 + 本条复盘时重点看的指标]
```

### 英文内容质量线

- 口语化美式英语，8 年级阅读水平，短句，禁用 "delve/vibrant/hidden gem/bustling" 这类 AI 味词
- 数字具体化："cheap" → "$3"，"fast train" → "217 mph"
- 每 3-5 秒一个信息点或画面切换，脚本里标出来
- 用 "you" 视角写，不用 "tourists/visitors"

## 模式 B：内容日历

1. 问清周期（默认 7 天、每天 1 条）
2. 按内容支柱配比排布（流量期参考配比在 `references/topic-library.md` 底部）
3. 每条给：日期、支柱、选题一句话、hook 方向、形式、CTA 类型
4. 混排形式：图文帖成本低，穿插在混剪之间保日更
5. 输出为表格 + 逐条一句话脚本方向；用户选中某条后进入模式 A 展开

## 模式 C：爆款拆解仿写

1. 拿到对标（逐字稿/链接描述/截图），先拆结构：
   - Hook 类型（对照 `references/hook-library.md` 的分类）+ 前 3 秒做对了什么
   - 节拍表：每个 beat 的功能（悬念/反差/价值点/情绪）和时长
   - 转化层：CTA 在哪、评论区怎么运营的
2. 再迁移：同结构换到用户的选题上，**换皮不换骨**——保留节拍和心理机制，替换题材和素材
3. 输出：拆解表 + 按标准交付包格式的仿写版本
4. 如果需要抓取对标内容（链接/账号），可用 agent-reach 或 /browse 获取逐字稿后再拆

## 模式 D：转化设计

读 `references/hashtag-cta-conversion.md` 的转化章节，按场景输出：
- 评论区回复模板（高赞评论借力、质疑回应、留资引导）
- DM 四步话术（qualify → value → offer → close），全英文
- 线索合格标准（日期/人数/城市/预算四要素），够格才推 WhatsApp 或转地接社
- Bio 和 link-in-bio 配置建议

## 模式 E：数据复盘

拿到数据后按诊断表定位问题，输出"诊断 + 3 条可执行动作"：

| 症状 | 诊断 | 动作 |
|------|------|------|
| 3 秒完播 < 60% | Hook 失败 | 换 hook 类型重发/下条改进；前 3 秒必须有画面冲击或反差句 |
| 3 秒好但整体完播 < 30% | 中段节奏塌了 | 砍时长到 30s 内；每 5s 检查是否有新信息点 |
| 高完播低涨粉 | 内容好但没人设/没关注理由 | 加系列感（Part 1/2/3）+ 口头 CTA "follow for part 2" |
| 高赞低评论 | 没留互动缺口 | 结尾埋问题/轻争议点；置顶评论提问 |
| 高互动零线索 | CTA 断层 | 检查评论关键词引导和 DM 响应速度；上 lead magnet |
| 某支柱持续跑赢 | 找到账号赛道 | 该支柱加浓度到 50%+，做成系列 |

复盘周期建议：每 10 条或每周一次，找出 top/bottom 各 2 条对比拆。

## 文件保存约定

- 单条交付包存到 `./tiktok-content/YYYY-MM-DD-<slug>.md`（slug 用英文短横线）
- 内容日历存到 `./tiktok-content/calendar-YYYY-MM-DD.md`
- 用户指定了其他路径时以用户为准；用户明确说"不用存"时只在对话输出

## 红线（每条内容出手前过一遍）

1. **政治敏感零接触**：不碰政治议题、领土表述争议、体制对比说教。"中国比你想的好"用画面和价格说话，不用旁白喊
2. **素材版权**：混剪素材优先自拍/CC0/已授权；提醒用户别直接搬运他人视频，TikTok 判搬运会限流
3. **不过度承诺**：免签政策按"截至发布时"表述并提醒观众查官方（政策会变）；行程报价不在公开内容里承诺具体价格
4. **音乐**：用 TikTok 商用曲库（账号做商业用途时 Commercial Music Library），爆款音频蹭热要确认可商用
