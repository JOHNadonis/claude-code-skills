# Claude Douyin Wenan

女生分享好物口吻。框架死、词灵活。像语音条，不像说明书。

## 输入

## 四框架（每条只选一种，槽位顺序别乱）

**痛点**  
可惜你 + 具体麻烦现场 + 不懂 + 产品好在哪 + 用法 + 效果

**效果**  
你一句 + 别人原话/反应 + 我就知道 + 产品买对了 + 效果

**性价比**  
不是 + 具体更贵/更麻烦的做法 + 用不起 + 而是 + 本品 + 更有性价比 + 一个实在好处

**场景**  
具体场景 + 用法 + 效果 + 轻推一句（现在就试/出门前化好）

批量默认：痛点 30% / 效果 30% / 场景 25% / 性价比 15%。同框架不连超 2 条。一条只打一个卖点。

## 怎么写才有人味

1. 每条要有**小事**（出汗、摘口罩、凑近看）+ **动作**（薄涂、按两下）
2. 大白话，一眼懂；长短句错落，5–7 行（别全压成 4 行）
3. 槽位词轮换：少刷「含金量」；性价比的「贵法」要换着写
4. 有爆款样例：学节奏和口头禅，别整段抄
5. 不编功效数据、真实评价、销量认证

别写：真正/其实/本质上、效果显著/值得入手、赋能闭环讲义腔。
