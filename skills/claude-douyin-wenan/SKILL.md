# Claude Douyin Wenan

把商品卖点写成可直接拍短视频的抖音带货短文案。像真人分享好物，不像品牌硬广。

## 与旧 skill `douyin-wenan` 的关系（重要）

本 skill 因用户对 `douyin-wenan` 产出不满意而建立，是**同四框架下的质量升级版**。

旧版常见翻车（写的时候主动躲开）：

| 旧版问题 | 本 skill 怎么做 |
|----------|----------------|
| 像填空：只换产品名/形容词 | 先建商品专属语言库（动词、部位、场景、关系反馈）再填槽 |
| 太乖太干：合规把爆款感写没了 | 允许口语夸张与关系梗；只禁医疗/绝对化/未确认数据 |
| 「不加标点」把语气弄死 | 默认可少标点；有爆款样例时允许 `!!`、问句语气跟随样例 |
| 批量同质：20 条同一张嘴 | 强制打散开头、卖点、关系角色、场景时刻 |
| 格式偶发带序号/外层 `[]` | 格式铁律写死，交付前自检 |
| 效果写虚：「提升体验」 | 必须落到可演的动作/体感/他人反应 |

当用户说「还是 douyin-wenan 那套四框架，但要好闻好读」或点名本 skill 名时，用本 skill，不要退回旧版口吻。

## 何时使用

- 用户要抖音 / 短视频带货文案、批量商品文案
- 用户给了爆款样例，要求模仿语言风格和结构批量改写
- 用户点名 `claude-douyin-wenan`、四框架文案、痛点/效果/性价比/场景型
- 用户明确对旧版 douyin-wenan 文案不满意，要求重做/升级
- 用户给了产品名、卖点、场景、链接，要求生成 N 条并保存 txt

相邻 skill 边界：

- 口播长稿 / 桌拍 45–60 秒 → `douyin-koubo`
- 视频贴片字幕 / 闺蜜种草叠字 → `douyin-product-caption-copy`
- 旧版四框架流水线 → `douyin-wenan`（默认不要用；除非用户点名旧版）
- 只要爆款感四框架批量短文案 → **用本 skill**

## 核心原则

1. **框架死，措辞活。** 四种框架的槽位顺序不能改；槽位里的词必须像真人说话，可以狠、可以甜、可以夸张。
2. **先判断商品，再套框架。** 框架不是填空题，不能只换产品名和形容词。
3. **一条一个核心卖点。** 不为了“信息全”把成分、规格、价格全塞进一条。
4. **爆款感优先于说明书感。** 先让人想点开/想试，再保证不违规。
5. **不编造事实。** 功效、留香精确小时、销量、认证、真实评价只能写已确认内容；他人反馈台词只作创意，不冒充真实评论。
6. **交付极简。** 用户要的是可直接复制的正文，不是讲解。

## 输入提取

从用户消息中识别：

| 字段 | 说明 | 缺失时 |
|------|------|--------|
| 产品名 | 口语短名，不要完整电商长标题 | 必问或从链接取 |
| 数量 | 生成条数 | 默认 20；用户说 100 就 100 |
| 爆款样例 | 风格/句式/情绪锚点 | 无样例则用默认口语 |
| 卖点 | 已确认卖点列表 | 至少 1 个可用卖点才写 |
| 场景 / 人群 | 洗澡、约会、早八、学生党等 | 用品类常识场景（B 级） |
| 商品链接 | 详情页 URL | 有则先读 `references/product-link-detail.md` |
| 格式偏好 | 分隔符、是否存文件、路径 | 见「默认交付」 |
| 禁用词 | 用户点名不要的词/句式 | 严格遵守 |

有链接时：先按 `references/product-link-detail.md` 建内部事实卡，只把 A 级事实写入文案槽位。链接失败且卖点不足 → 要截图/标题/确认卖点，不猜。

## 内部商品判断卡（不对外输出）

动笔前必须能答清：

1. 这是什么，不是什么（真实品类与主用法）
2. 谁、在什么时刻会想买
3. 最具体的一个烦点 / 尴尬瞬间 / 日常动作
4. 差异点翻成可感知的动作、触感、气味、用后状态
5. 核心卖点 vs 次要卖点（一条只用核心）
6. 本批评专属语言库（动词、身体部位、场景词），避免全场同义替换

答不清就不要开始套框架。

## 唯一允许的四种框架

每条只选一种。禁止自创第五种、混合两种、改槽位顺序、删必要槽位、前后再加故事段。

### 1. 痛点型

公式：`可惜你 + 痛点 + 不懂 + 产品含金量 + 用法 + 效果`

顺序硬约束：

1. 以「可惜你」开头
2. 一个具体痛点（别写空泛“皮肤不好”）
3. 必须出现「不懂」
4. 产品或产品含金量
5. 简单用法
6. 自然效果

示例：

```text
可惜你还在硬搓鸡皮
不懂儒意红石榴磨砂膏的含金量
冲澡时打圈揉开
洗完直接香到腌入味
```

### 2. 效果型

公式：`你一句 + 他人反馈 + 我就知道 + 产品 + 买对了 + 效果`

顺序硬约束：

1. 「你一句」+ 他人原话式反馈
2. 可补发现动作（追着闻、贴贴、要链接）
3. 必须出现「我就知道」
4. 产品
5. 必须出现「买对了」
6. 自然效果

示例：

```text
你一句身上好香啊
crush追着贴贴的样子
我就知道
儒意红石榴磨砂膏买对了
留香真的顶
```

### 3. 性价比型

公式：`不是 + 高价替代 + 用不起，而是 + 本品 + 更有性价比 + 优势`

顺序硬约束：

1. 「不是」开头
2. 高价替代 / 高成本做法
3. 必须出现「用不起」
4. 「而是」转折
5. 本品
6. 必须出现「更有性价比」
7. 一个已确认或低风险优势

示例：

```text
不是那些天价磨砂我用不起
而是儒意红石榴磨砂膏更有性价比
洗完又嫩又香
钱花在刀刃上
```

### 4. 场景型

公式：`场景 + 产品用法 + 效果 + 行动指令`

顺序硬约束：

1. 具体场景（时间/地点/动作）
2. 产品 + 简单用法
3. 自然效果
4. 轻行动指令（现在就洗 / 今晚就试 / 出门必带）

示例：

```text
晚上冲澡时
挤一泵儒意红石榴磨砂膏打圈揉
洗完身上香到发里去
现在就去囤
```

轻行动指令白名单（可改写，保持“轻推”）：

- 现在就去囤 / 今晚就试 / 早起就用
- 家里可以囤一瓶 / 出门必带
- 这个场景真的用得上 / 活动合适可以入

## 批量分配

| 条数 | 规则 |
|------|------|
| < 8 | 按用户指定类型；未指定则四型尽量都出现 |
| ≥ 8 | 四型都要出现 |
| 默认比例 | 痛点 30% / 效果 30% / 场景 25% / 性价比 15% |
| 打散 | 同框架不得连续超过 2 条 |
| 去重 | 同一开头、同一核心卖点不得连着重复；整批避免只换形容词 |

用户指定「只要痛点型」等时，服从用户，比例规则让路。

## 写作流程

1. 提取输入 → 必要时尚问 1–2 个关键缺口（产品名/卖点）
2. 有链接则取详情，建事实卡
3. 完成商品判断卡 + 专属语言库
4. 按比例分配每条的框架类型（内部清单，不输出）
5. **先列槽位，再填词，再断行**——禁止先自由写再事后硬套
6. 每条整理成 **4–7 行**（按说话停顿断句；相邻槽位可同行，同槽位可拆两行，顺序不变）
7. 框架验收 + 合规验收
8. 按交付格式输出 / 存 txt

有爆款样例时：

- 学它的节奏、夸张程度、人称、收尾语气（如「你真的顶!!」「恨不得天天贴贴」）
- 不逐句抄样例；样例只定调，事实仍以商品为准
- 样例里的关系词（crush/闺蜜）可复用为效果型创意反馈，不写成真实客户证言

## 口语与形态（质量阈值）

目标口吻：**闺蜜语音条 + 一点点犯规感**，不是客服话术。

- 简体中文；短句优先；像跟朋友说话
- 每行大约 4–16 字，允许 2–6 字反应句（真的顶 / 绝了 / 爱了）
- 产品名用口语短名，不用电商长标题全文
- 卖点转换链：`特性 → 用起来什么感觉 → 日常省什么事 / 谁会什么反应`
- 网络热词克制：一条最多一个；整批轮换，不要 100 条全是「绝绝子」
- 标点：默认可以少标点、靠换行呼吸；若用户样例有 `!!`、问句，允许同强度语气
- 不写 BGM、分镜、拍摄建议（除非用户另要）

### 必须像“能拍出来”

每条至少有一个**可表演镜头**：搓、揉、冲、贴、闻、回头、要链接、钻被窝……  
如果一条里只有抽象评价（好用/推荐/提升幸福感），重写。

### 关系与反馈角色库（整批打散，勿条条 crush）

效果型与部分场景收尾可轮换：

- crush / 对象 / 他
- 闺蜜 / 姐妹 / 室友
- 同事 / 妈妈 / 陌生侧目
- 自己闻自己 / 隔天衣领

### 可感表达优先（按品类自建，勿照抄到不相关品）

洗护香氛例：

- 打圈揉 / 冲两下 / 洗完 / 闻起来 / 贴上来
- 香到腌入味 / 走路带香 / 隔天还在 / 鼻子贴上来

护肤身体例：

- 薄涂 / 厚敷 / 一抹化开 / 摸着润 / 不拔干 / 起皮没那么烦

避免广告腔与旧版干句：

- 本品采用先进技术 / 蕴含多重珍贵成分 / 打造卓越体验
- 使用感受良好 / 值得拥有 / 推荐入手 / 效果显著
- 只有产品名换皮的同句重复

### 反同质化（批量时强制）

内部生成时维护去重表，确保相邻条文在至少 3 维不同：

1. 开头钩子（痛点场景 / 他人原话 / 高价对象 / 时刻场景）
2. 动作词
3. 结果镜头或关系角色

同一框架内禁止只改一个形容词交差。性价比型的「高价替代」也要换说法（天价磨砂 / 专柜身体乳 / 贵妇 SPA / 网红溢价…），不要 15 条都「不是大牌用不起」。

## 合规边界

禁的是**违规承诺**，不是**口语张力**。

禁止无依据的绝对化、医疗化、承诺疗效：

- 第一 / 最强 / 永久 / 100% / 治疗 / 修复屏障 / 消炎
- 保证不过敏 / 一用就好 / 再也不会

允许（在无精确数据时）的爆款口语：

- 香到腌入味 / 恨不得天天贴贴 / 你真的顶 / 有点犯规
- 隔天还在（不要写成「留香 72 小时」除非已确认）
- 追着闻、要链接、贴贴（创意反馈，非真实证言）

优先低风险且仍有画面的说法：

- 没那么干 / 摸着滑一些 / 洗完愿意凑近 / 用着更省心

未确认时不要写：精确留香小时数、回购次数、家人真实反馈、销量排名、认证。

## 格式铁律（用户已反复纠正，必须遵守）

批量正文必须同时满足：

1. **不要**在文案开头加左侧 `[`
2. **不要**在文案结尾加右侧 `]`
3. **不要**加「文案 1」「文案一」等序号
4. **不要**加标题、框架名、解释、前后说明夹在正文里
5. 文案与文案之间：**单独一行**只有 `[]`
6. 文案内部：正常换行，不加包裹符

正确：

```text
可惜你还在硬搓鸡皮
不懂儒意红石榴磨砂膏的含金量
冲澡时打圈揉开
洗完直接香到腌入味
[]
你一句身上好香啊
crush追着贴贴的样子
我就知道
儒意红石榴磨砂膏买对了
留香真的顶
```

错误：

```text
[可惜你还在硬搓鸡皮
...]
文案 1
[]
文案 2
```

## 默认交付

| 场景 | 行为 |
|------|------|
| 用户说「保存 / 导出 / txt / 文档」或批量 ≥ 20 | 写入 `.txt`，回复只给路径 + 一句验收 |
| 用户说「只发聊天里 / 先看看」 | 仅聊天输出，仍用 `[]` 分隔 |
| 未指定路径 | 优先 `~/Desktop/{产品口语名}_{N}条文案.txt`；若存在 `/Volumes/OS/短视频素材/` 可同步一份 |
| 文件名 | 去掉特殊符号；示例：`儒意红石榴磨砂膏_100条文案.txt` |

聊天里若先预览后保存：预览也必须已是铁律格式，保存时原样落盘，不要再包一层说明。

最终手递（存文件时）只说：

- 文件路径
- 条数
- 四型是否按比例覆盖（一句话）
- 若链接失败等限制，点一句

不要在文件正文里写验收说明。

| 类型 | 还原链 |

| 效果 | 你一句 / 他人反馈 / 我就知道 / 产品 / 买对了 / 效果 |

| 场景 | 场景 / 产品用法 / 效果 / 行动指令 |

且每条 4–7 行。无法还原 → 重写，不交付，不另造公式。
