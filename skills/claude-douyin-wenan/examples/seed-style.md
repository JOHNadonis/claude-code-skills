# 风格与格式金样（儒意红石榴磨砂膏会话沉淀）

## 爆款原句气质

```text
不过用它洗了个澡而已
身上都香的腌入味了
crush恨不得天天贴贴
儒意红石榴磨砂膏
你真的顶!!
```

可学：

- 轻描淡写的使用动作起手
- 夸张但口语的体感结果（腌入味）
- 关系反馈（crush 贴贴）作社交证明
- 产品名单独一行落地
- 短促强安利收尾

不可学成：

- 编造真实用户评论
- 每条都用完全同一套结尾
- 把样例整段复读 N 次只换产品名
