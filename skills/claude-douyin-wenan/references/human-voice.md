# 人味规则（改编自 rn-renhua，面向抖音短带货）

> 来源启发：`Pluviobyte/rnskill` → `rn-renhua`（去 AI 味精修）  
> 本文件只服务短视频带货文案，不照搬长文技术写作。

## 缺人味的真正原因

不是不够口语，而是 **壳太整齐**：

1. 槽位词条条复读（含金量 / 我就知道 / 更有性价比）
2. 每条信息密度、句长、情绪强度几乎一样
3. 只有「评价」没有「当场发生的小事」
4. 对比句只搭架子，不说具体吃亏点

框架保留槽位顺序；人味来自 **槽位里的具体生活**，不是再加形容词。

## 写之前先抓 4 桶料（内部，不输出）

从用户爆款样例 + 卖点里拆：

| 桶 | 要什么 | 粉底液例子 |
|----|--------|------------|
| 事实 | 品名、用法、已确认卖点 | 焊脸、防水防汗、控油 |
| 判断 | 说话人认定什么 | 这瓶夏天够权威 |
| 经验 | 具体瞬间/失败/省事 | 厕所补妆、摘口罩花一半 |
| 动作 | 观众能跟着做 | 薄涂、按两下、别猛擦汗 |

每条至少落到 **经验 + 动作** 各一个。只有「好用/推荐」= 没人味。

## 槽位怎么说人话（顺序不变，用词可变）

### 痛点型

固定顺序：可惜你 → 痛点 → 不懂 → 产品值在哪 → 用法 → 效果

- 「痛点」写成 **丢人/麻烦的小现场**，别写抽象皮肤问题  
  好：一出汗妆花得像花猫 / 厕所补到心烦  
  差：妆容持久度不佳
- 「不懂…」后面 **不要条条都写「含金量」**  
  可轮换：为啥稳、厉害在哪、值在哪、到底行不行  
  保留「不懂」二字即可
- 效果用 **自己或别人当场反应**，少用空夸

### 效果型

固定顺序：你一句 → 他人反馈 → 我就知道 → 产品 → 买对了 → 效果

- 「你一句」后的原话要像真人会说的半截话，可带语气  
  好：unny真的太权威了 / 焊在脸上了吧 / 链接快发我  
  差：这款产品持妆效果非常出色
- 反馈动作要具体：凑近看、盯着笑、群里要链接  
- 「买对了」可与产品名同行，避免机械断行五连拍  
- 效果句写 **看见/摸到/省事的结果**，别写心情总结

### 性价比型（高风险 AI 壳）

固定顺序：不是 → 高价替代 → 用不起 → 而是 → 本品 → 更有性价比 → 优势

`rn-renhua` 会把「不是 A 而是 B」当 AI 壳。本 skill **因框架必须保留**，但要这样救人味：

1. A 必须是 **具体贵法/麻烦法**（请化妆师、专柜小样拼、天价持妆瓶），禁止「高端方案」
2. 「用不起」后半句不要空；可接一句自己的真实顾虑（学生党/打工人）
3. 「更有性价比」后 **立刻** 跟可感优势（焊脸、清透、控油），禁止再讲大道理
4. 整批性价比型的「高价替代」必须轮换，禁止 15 条同构填空
5. 收尾用具体好处，不用「值得拥有」

### 场景型

固定顺序：场景 → 用法 → 效果 → 行动

- 场景写 **钟点/天气/正在干嘛**，别写「日常使用时」
- 行动指令像催朋友，不像按钮文案  
  好：出门前化好 / 热天现在就试  
  差：立即下单锁定优惠

## 节奏：故意不齐

参考爆款与叠字 skill：长短错落，不要每行同等长度。

- 可有 2–4 字短行（真的顶 / 焊住了）
- 可有一句稍长的现场描述
- 同一条里避免「主谓宾、主谓宾、主谓宾」齐步走
- 允许一点口头啰嗦：特别、有点、真的、吧、啊（一条点到为止）

## 人味加分（短带货版）

- 第一人称小判断：我先美了 / 我自己也服气
- 轻微不完美：有点烦、有点假、有点慌
- 时间钉：中午、下班、摘口罩那一下
- 身体钉：T区、嘴角、口罩勒的地方
- 关系钉：闺蜜凑近、同事偷看、群里要链接（轮换）

### 带货 AI 腔（本域增补）

- 使用感受良好 / 效果显著 / 值得入手 / 强烈推荐
- 打造卓越体验 / 多重呵护 / 匠心配方
- 条条「XX的含金量」+ 条条「我就知道」+ 条条同款收尾
- 全篇句长几乎一样、情绪温度一样

### 需要观众想一秒的词

除非用户样例自带，否则少用：破防、硬刚、开挂、杀伤力、横着走、拉满
