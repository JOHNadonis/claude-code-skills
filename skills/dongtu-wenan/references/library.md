# 动图文案素材库

## 0. 人味增强规范（2026-08-15 老大手拆真实爆款，写作前必读）

> 老大原话："总感觉少了一些人味，人味可能就是没那么完美，你写的太完美。" 拆解 16 条真实爆款后得出以下 10 条"人味配方"。**宁可糙、宁可满、宁可用梗，也不要工整得像范文。**

1. **情绪外放，感叹号当逗号用**：真实文案感叹号高频甚至「!!」。情绪是满的、外放的，不是收着的。
   - 例：「你不薅就真的亏!!」「拜见BUV大王!」「伊风蓬蓬粉也太牛了吧」
2. **品牌喊话式（网感，不是文艺腔）**：直接点名品牌、像网友喊话，别用「XX你是真顶」这种书面腔。
   - 例：「达尔肤真牛」「拜见BUV大王」「蔡徐坤还是太权威了!」「夏伯雅莲真有你的!」「elle你出来解释一下」「伊风蓬蓬粉也太牛了吧」
3. **蹭明星/网络梗**：权威梗、拜见梗、明星名，敢用就有网感。
4. **谐音梗随手用**：我勒个痘（痘→豆）、护肤=护夫。
5. **社交验证对象具体到有名字**：别只写"闺蜜/同事/朋友"，要具体——暧昧对象、男友、对象、同事追问800遍。
   - 例：「暧昧对象还以为我天天洗头」「男友说：你睡过的枕头都是香的」「素颜对象问我是不是抹粉了」
6. **夸张数字给画面**：800遍、38度外勤、洗一次蓬松好几天。
7. **身体/生活细节具体到狼狈**：身上都臭了头发还是香的、发圈都扎不住了、睡过的枕头都是香的、哪里扁塌扑哪里。
8. **人群点名，让人一秒对号入座**：油皮天菜出现了、熬夜暗沉脸、懒人、手残党。
9. **价格钩子 + 亏损恐惧**：「几十一片你嫌贵我能理解」→「你不薅就真的亏」。
10. **态度宣言**：哄男人的事老娘顺手就做了、我不会让你再羡慕别人。

**落地口诀**：每篇至少命中 2-3 条——要么有「!!」级情绪，要么有品牌喊话，要么社交对象具体到人，要么有夸张数字/狼狈细节。**先把自己当成刷到这条的人，脱口而出，再落笔。**

### 正反对照：说明书腔 vs 人话（写完后逐句自查）

> 公式骨架没错，错在公式后面接的是"说明书"还是"人话"。判据就一条：**这句子有没有"人"——态度、戏、画面、梗。有=留，纯功能罗列=换。**

| 错（说明书腔，没人） | 对（人话，有人） |
|---|---|
| 满手泡泡 洗完不紧绷 | 洗完脸 素颜都被夸皮肤好 |
| 拖一遍 满屋清香 | 老公进门就问"你今天请保洁了?" |
| 氨基酸温和清洁 油光也淡了 | 同事都问我换了什么护肤品 |
| 睡前滴两滴 眼周润润的 | 眼周润得能反光 |
| 哑光雾面 高级感 | 涂完抿一下 温柔到犯规 |
| 免洗免吹 干爽蓬松 | 口红可以不补 但发根一定要支棱起来 |

**高频"有人味"句种子（直接抄气质，不抄原句）**：
- 废话!老娘用的XX（傲娇）
- 想照镜子八百遍 / 想亲自己一口（离谱自恋）
- 老公进门就问"你今天请保洁了?"（戏）
- 温柔到犯规 / 吨吨吨 / 用到地老天荒（流行语/梗）
- 知足吧 / 谢天谢地不用重画（丧+真实）
- 同事还以为我天天洗头（借他人之口）

## 1. 情绪词库（按文案类型分）

### 痛点型 · 戳痛点词
- 可惜你 / 居然还有人不知道 / 别再踩坑了 / 我真的求求了
- 还在...吗？/ 每到...就... / 你是不是也...

### 效果型 · 社交证明词
- 被夸了 / 被追问 / 素颜出门 / 朋友都说 / 回头率变高
- 你一句"..."，我就知道...买对了

### 性价比型 · 划算词
- 不是...用不起 / 更有性价比 / 平替 / 闭眼入 / 囤 / 价格打下来
- 大容量 / 家庭装 / 一罐顶三罐 / 天天用不心疼

### 场景型 · 场景 + 行动指令
- 场景：睡前 / 洗澡后 / 军训前 / 开学前 / 约会前 / 通勤 / 出门前 / 换季
- 指令：必囤 / 听我的 / 现在下单 / 趁活动 / 赶紧安排上 / 人手一罐

## 4. 卡审提醒（红线，一碰就废素材）

来自选品表投放备注的常见卡审点，写文案时逐条自查：

**极限词**：最、首、极、王牌、绝对、第一 —— 禁用
**功效承诺**：去除、告别、根治、修复、不再困扰、阻断、抑制、祛、消 —— 禁用
**医疗字眼**：痤疮、毛囊炎、酒糟鼻、红肿、红血丝、毛囊炎 —— 禁用
**绝对化描述**：无添加、纯天然、无副作用、不刺激、零风险 —— 慎用
**时间/价格承诺**：特定天数见效、具体成交价格 —— 部分类目禁用
**对比贬低**：不能说效果对比、贬低竞品
**专利话术**：提到专利必须附专利号 + 专利种类
**违禁词类别**：禁用"黑奴""平民""抠搜女大学生""商战"等可能引发歧义的词

> 提示：不同类目卡审严格度不同，美妆/个护最严，写之前先按上表自查，拿不准就把功效词换成体验词（"清爽""好推开""舒服"）。
