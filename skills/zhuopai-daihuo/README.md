# zhuopai-daihuo（桌拍带货文案生成器）

抖音桌拍带货短视频文案生成器。由11篇抖音桌拍带货爆款文案拆解提炼而成。

## 文件结构
- `SKILL.md` — skill 主文件（触发规则 + 工作流程 + 输出规范）
- `references/templates.md` — 5类文案模板（功效护肤/口腔气味/日用品母婴/美妆工具/彩妆多SKU）
- `references/library.md` — 通用素材库（开头钩子7种/中间钩子/逼单话术/桌拍动作/语言风格）

## 使用方式
把 SKILL.md 放入你的 skill 目录（如 Claude 的 skills/、FastClaw 的 skills/ 等），
或直接将本包导入支持 .skill 格式的平台。

## 工作流
用户发来商品名称 + 商品详情 → 按品类匹配模板 → 提取卖点 → 输出一篇完整文案（不输出思考过程）。

## 规则要点
- 只输出文案正文，不输出思考过程
- 资质类信息（检测报告/专利/浓度）只用用户提供的，不编造
- 一条文案一个主钩子，中间2-4个卖点，结尾必须逼单
