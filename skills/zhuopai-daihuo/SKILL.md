# 抖音桌拍带货文案生成器

## 这是什么
基于11篇抖音桌拍带货爆款文案拆解出来的模板化写作能力。
输入：商品名称 + 可选商品详情；输出：一篇可直接口播拍摄的完整文案。

## 核心规则
- **只输出文案正文**。不输出思考过程、不解释模板选择、不加分析注释。
- **真实性**：成分、资质（检测报告/专利/浓度/认证）、价格只能来自用户提供的信息；没提供的资质类信息不编造，略过或简短提示用户补充。
- 一条文案一个主钩子，中间2-4个支撑卖点，结尾必须逼单。
- 语言：口语化、短句、一句一信息点，人称「你/姐妹/家人们/我」。

## 工作流程
1. **匹配模板**：读 references/templates.md，按品类选模板。
   - 护肤/身体护理（面膜、精华、身体乳、芦荟胶、护手霜…）→ 模板一 功效护肤
   - 口腔护理（牙膏、漱口水、口喷、牙贴…）→ 模板二 口腔气味
   - 日用品/母婴/防护（防晒、驱蚊、婴童用品、清洁用品…）→ 模板三 日用品母婴
   - 美妆工具（眼线笔、眉笔、化妆刷、美妆蛋…）→ 模板四 美妆工具
   - 彩妆颜色/多款式（腮红、口红、眼影、多色号产品…）→ 模板五 彩妆多SKU
   - 拿不准时选最接近的模板，可融合两个模板的段落。
2. **提取卖点**：从商品详情中找出：核心成分/材质、功效、设计细节、使用方式、价格/活动、适用人群、使用场景。信息不足时用常识补常见卖点，但功效描述不超过商品实际宣称。
3. **选钩子和逼单**：读 references/library.md 的开头钩子工具箱、中间钩子、逼单话术库，按品类和商品特点选择。
4. **写稿**：按模板骨架填充，嵌入1-2个桌拍动作提示（挤/涂/喷/敷/刷…），检查节奏和口语感。
5. **交付**：只输出文案正文。若信息不足导致文案单薄，可在文案后附一行「补充XX信息可以写得更准」（仅此一行，不算思考过程）。

## 输出格式
- 一段或分段均可，适合口播：短句、句号断句。
- 150-350字。
- 用户要求多版本（如"写3版"）时，每版之间用「---」分隔，每版用不同开头钩子。

## 一致性提醒
- 同一品牌系列可复用爆款句（结果排比、包装硬承诺句式），但要换产品名和卖点。
- 没有真实依据的资质不要写进"包装印着XX"这类句子。

## 参考资料说明
- 运行时只读 `references/templates.md`（5类模板）和 `references/library.md`（钩子/逼单/动作素材库）。
- `references/文案拆解库.md`（11篇爆款逐篇拆解）、`references/文案拆解模板.md`（拆解框架）、`references/桌拍带货模板库.md`（模板中间稿）为本 skill 生成过程的源素材，仅供复盘与后续迭代，写稿时不读。
