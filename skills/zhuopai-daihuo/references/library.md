# 素材库（跨模板通用）

## 1. 开头钩子工具箱（7种）

| 类型 | 例句 | 适用 |
|---|---|---|
| 诱惑式利益承诺 | 你熬的越凶，用它效果就越明显 | 功效型产品 |
| 质疑反驳式 | 真不是智商税 | 有争议/智商税重灾区品类 |
| 共鸣提问式 | 有没有像我一样…蚊子重点关照对象 | 人群标签强的产品 |
| 人群狂欢式 | 荔枝脑袋真的可以无脑冲 | 口味/兴趣圈层产品 |
| 场景预警式 | 开学军训前，听我的，提前备好 | 季节性/时间节点产品 |
| 薅羊毛价格式 | 赶紧来薅大羊毛 | 清库存/活动品 |
| 自用习惯式 | 出去玩涂防晒，我都是用XX | 复购型日用品 |
| 人群反向筛选式 | 但凡你不XX，你都体会不到这个XX | 有明确目标人群（熬夜党/油皮/新手…），先筛走非目标反而更抓 | 
| 选择题悬念式 | 该不会你还在纠结A还是B？ | 多SKU/多色号/两款产品，制造决策冲突留人 |
| 感官冲击式 | 拆开不到五分钟，整个屋子都是XX香 | 香氛/味道/质地/触感等感官卖点强的产品，直接用结果开场 |

选钩子原则：先看商品最大的"确定性场景/人群"，再看价格有没有故事可讲，最后看品类有没有争议点。

## 2. 中间钩子（防划走，穿插在卖点里）

- 价格反差钩子：原价贵 → 活动价便宜（"之前XX，现在XX才什么价"）
- 人群钩子：XX人群一定要试试
- 成分钩子：堆专业成分名（复活草/积雪草/烟酰胺/XX酶）
- 感官钩子：质地/味道/肤感的画面描写（奶冻质地/柑橘香蔓延到舌根）
- 社交钩子：素颜被朋友追问/亲测场景验证
- 设计钩子：倒着喷/三合一/按压泵等细节
- 数据钩子：官方X小时 + 亲测场景（数据给底气，亲测给真实感）

## 3. 招牌信任句式（博主爆款DNA，可按需复用）

- 「包装上印着XX…没点实力/真本事哪敢这么写」（仅限真实包装信息）
- 「之前XX很贵，现在活动/清库存，链接里才什么价」
- 「XX酶/XX专利成分，从源头分解XX」
- 「不是普通XX / 和普通XX完全不一样」
- 「一边A一边B」排比（一边控出油，一边焕亮肌肤）
- 「现在XX了，XX了，XX都自信多了」结果短排比
- 「唯一的缺点就是发现得太晚」反向缺点

## 4. 逼单话术库

- 活动限时：趁现在有活动/活动做不了多久
- 囤货量化：多囤两瓶/囤两组够一夏天/囤两包用很久
- 价格锚点：之前70多，两罐才什么价
- 赠品加量：加量不加价，还送XX
- 预防式：别等晒得难受才想起
- 直接指令：听我的，囤XX色/闭眼入

## 5. 桌拍动作提示词（文案里自然嵌入1-2个）

挤、涂、喷、刷、敷、刮、咔咔两下、咕嘟咕嘟、一抹就化开、挤这么点直接干刷出泡沫

作用：文案自带动作脚本，拍摄时照着做就有画面。

## 6. 语言风格规范

- 口语化：短句、一句一信息点、句号断句
- 人称：你/你们/姐妹/家人们/我/咱们
- 高频口语词：可不是、巨、贼、那叫一个、真的、完全、就
- 夸张比喻制造记忆点：像被无花果腌入味儿/像给娃套了个隐形蚊帐
- 情绪词增强代入：救了我大命/太良心了/太懂我了
- 共鸣式自嘲：你看看我这个化妆小白/手残党
- TTS口播情绪标记：适当位置嵌入「哈哈哈」作为情绪/语气标记——自嘲转折处、强调/抖包袱后、把话说满前的一下缓冲（如"以前我也这么干，哈哈哈"），语音合成会读出情绪，更像真人；别密集刷，一篇最多2-3处
