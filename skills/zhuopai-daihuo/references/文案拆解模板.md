- 开头（0-3秒）：
  - 钩子类型：（痛点直击 / 反常识 / 利益承诺 / 场景代入 / 悬念提问 / 制造冲突 …）
  - 原句摘录：
- 中段（产品展示）：
  - 结构顺序：从__到__（如：问题→方案→对比→证明）
  - 卖点排序逻辑：
  - 展示方式：（口播 / 字幕 / 道具演示 / 前后对比 …）
- 结尾（促单）：
  - 逼单方式：（限时 / 限量 / 价格对比 / 售后承诺 / 人群筛选 / 从众效应 …）
  - 原句摘录：

## 二、语言风格拆解
- 语气调性：（口语化 / 接地气 / 专业 / 夸张亢奋 / 闺蜜聊天 …）
- 句式特点：（短句轰炸 / 排比 / 设问自答 / 命令式 / 反问 …）
- 高频词汇 / 口头禅：
- 人称视角：（你 / 你们 / 大家 / 姐妹们 / 家人们 …）
- 节奏感：（停顿 / 加速 / 重音处 …）

## 三、钩子拆解
- 开头钩子：类型 + 为什么有效
- 中间钩子（防划走）：每隔几秒一个刺激点，是什么
- 结尾钩子（促进转化）：是什么

## 四、可复用公式
- 一句话总结这篇的结构公式，例如：
  「痛点场景(2s) + 产品出场(1s) + 3个卖点逐条演示 + 价格锚点 + 逼单CTA」
