# 抖音桌拍带货文案模板库

> 由11篇爆款文案拆解提炼而成。共5类模板 + 通用素材库。
> 使用方式：发我商品名称 + 商品详情 → 我按品类匹配模板 → 输出一篇完整文案。

---

## 模板一：功效护肤类

**适用**：面膜、精华、身体乳、芦荟胶、护手霜等主打成分/功效的品类
**来源**：第1篇复活糖面膜、第10篇芦荟胶

```
开头钩子（二选一）：
  A 诱惑式：你越[痛点]，用它效果就越明显
  B 场景预警：[时间节点]前，听我的，[产品]提前备好
产品名 + 价格锚点：就[品牌]这款[产品]，之前[单价]不便宜，
  现在商家冲[节点]销量，链接里[数量]到手才[价格]
差异化 + 人群：这可不是普通[品类]，尤其[痛点人群]，一定要试试
成分功效：添加了[A]+[B]两大核心成分，就是能[功效1]的同时还[功效2]，
  一边[功效3]一边[功效4]
肤感体验：[质地]，上脸[感受]，用完那叫一个[效果]
效果证明：现在我[场景]出门，朋友都追着问是不是[效果外显]了
信任背书（有真实资质才写）：有正规[检测报告]，可不是杂牌能比的
反向缺点：唯一缺点就是发现得太晚
逼单：趁现在有活动，多囤[数量]慢慢用
```

## 模板二：口腔/气味类

**适用**：牙膏、漱口水、口喷、牙贴等
**来源**：第2篇美白牙膏、第3篇漱口水、第4篇荔枝牙膏

```
开头钩子（三选一）：
  A 质疑反驳：真不是智商税，[品牌]把[硬承诺]印在包装上，没点实力是真不敢
  B 人群狂欢：[XX脑袋]无脑冲，尤其[痛点人群]一定要试试
  C 热度+痛点：[品牌]新出的[产品]真的夯爆了，[痛点场景]的一定要试试
破除旧认知：以前总觉得[旧产品缺点]，这款真的刷新认知
味觉/嗅觉层次：入嘴是[味道1]，紧接着[味道2]，最后[味道3]慢慢散开，
  刷/含完连呼吸都带着[味道]
成分源头论：添加了[XX酶]，能从源头分解[糖分/残渣]
使用演示（桌拍动作）：[形态卖点]，你就[挤/喷]这么点，直接[操作]，
  能[可拍的效果]
结果短排比：现在[结果1]了，[结果2]了，[说话/自信]都[改变]了
逼单：[活动]做不了多久，趁划算多囤
```

## 通用素材库

### 开头钩子7种
1. 诱惑式利益承诺：「你越XX，用它效果就越明显」→ 功效型
2. 质疑反驳式：「真不是智商税」→ 有争议品类
3. 共鸣提问式：「有没有像我一样…」→ 人群标签强
4. 人群狂欢式：「XX脑袋无脑冲」→ 圈层产品
5. 场景预警式：「开学军训前提前备好」→ 季节性产品
6. 薅羊毛价格式：「赶紧来薅大羊毛」→ 清库存/活动品
7. 自用习惯式：「出去玩我都是用XX」→ 复购日用品

### 招牌信任句式
- 包装印着XX…没点实力/真本事哪敢这么写（仅限真实信息）
- 之前XX很贵，现在活动/清库存，链接里才什么价
- XX酶/专利成分，从源头分解XX
- 不是普通XX / 和普通XX完全不一样
- 一边A一边B
- 现在XX了，XX了，XX都自信多了
- 唯一缺点就是发现得太晚

### 逼单话术
活动限时 / 囤货量化（多囤两瓶/囤两组够一夏天）/ 价格锚点 / 赠品加量 / 预防式（别等晒得难受才想起）/ 直接指令（听我的囤XX）

### 桌拍动作提示词
挤、涂、喷、刷、敷、刮、咔咔两下、咕嘟咕嘟、一抹就化开、挤这么点直接干刷出泡沫

### 语言风格
口语化短句一句一信息；人称「你/姐妹/家人们/我」；高频词：可不是、巨、贼、那叫一个、真的；夸张比喻制造记忆点；情绪词：救了我大命/太良心了
